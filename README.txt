ME LIVING Gästeplattform

Enthaltene Dateien:
- index.html: Startseite mit Unterkunftsauswahl
- villa-am-kurpark.html: vollständiger Gästeguide
- altstadt-apartment-lemgo.html: vorbereitete Platzhalterseite
- apartment-kirchstrasse.html: vorbereitete Platzhalterseite
- apartment-brunnenstrasse.html: vorbereitete Platzhalterseite

So veröffentlichen Sie die Plattform:
1. Laden Sie den gesamten Ordner auf einen Webspace oder Hosting-Dienst hoch.
2. Die Startseite muss index.html heißen.
3. Öffnen Sie anschließend die öffentliche Webadresse.
4. Hinterlegen Sie den Link in Smoobu und in Ihren automatischen Nachrichten.

Empfohlene Adresse:
https://guide.meliving.de

Wichtig:
Alle Dateien müssen gemeinsam hochgeladen werden, damit die Verlinkungen funktionieren.
